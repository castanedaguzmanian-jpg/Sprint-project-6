In this project, I worked as a data analyst for Ice, an online video game store that sells games worldwide.
The goal was to identify patterns that determine whether a video game is commercially successful, in order to detect promising projects and support advertising campaign planning.
The analysis was conducted using historical sales data up to 2016, simulating a real-world scenario in which it is December 2016 and the company is planning its 2017 marketing strategy.
The dataset included information such as game reviews (user and expert scores), genres, platforms (e.g., Xbox, PlayStation, PC), regional sales, and ESRB age ratings.
Key tasks performed:
Cleaned and prepared the dataset by standardizing column names, converting data types, and handling missing values (including TBD ratings).
Calculated total global sales by aggregating regional sales data.
Analyzed game release trends over time and assessed the relevance of different historical periods.
Evaluated sales performance across platforms, identifying market leaders, emerging platforms, and declining ones.
Used boxplots to compare global sales distributions by platform and assess statistical differences.
Examined the relationship between user and critic reviews and sales using scatter plots and correlation analysis.
Analyzed sales performance by genre to identify the most profitable categories.
Built regional user profiles (North America, Europe, Japan), identifying top platforms, genres, and the impact of ESRB ratings.
Tested statistical hypotheses comparing:
Average user ratings for Xbox One vs PC platforms.
Average user ratings for Action vs Sports genres.
Interpreted results using hypothesis testing with a defined alpha level and clear business conclusions.
This project demonstrates the ability to transform raw data into actionable insights that support marketing strategy, product selection, and regional targeting decisions.
Tools used: Python (pandas, NumPy, SciPy), Matplotlib, Jupyter Notebook
